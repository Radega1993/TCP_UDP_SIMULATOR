Configuración IPv4

Introduce dos equipos y una máscara para saber si están en la misma red.

Teoría esencial

¿Qué es una IP?

Identifica lógicamente a un dispositivo dentro de una red.

¿Qué es una red?

Conjunto de direcciones que comparten la misma parte de red.

¿Qué hace la máscara?

Separa los bits de red de los bits disponibles para hosts.

Resultado principal

No están en la misma red

El origen y el destino pertenecen a subredes diferentes. Para comunicarse, el equipo origen necesita usar el gateway.

Para explicar en clase

  • La máscara /24 deja los tres primeros octetos como red.
  • 192.168.1.10 pertenece a 192.168.1.0/24.
  • 192.168.2.20 pertenece a 192.168.2.0/24.
  • Si las redes son distintas, se necesita gateway.
